# Калькулятор математических формул с памятью (Java Swing)

Учебная лабораторная работа по Java Swing, реализующая графический интерфейс для расчета двух сложных математических формул с переменными $X$, $Y$, $Z$ и поддержкой базовых функций памяти (`MC`, `M+`).

## 🚀 Функционал приложения

* **Расчет двух формул**: Переключение между формулами с помощью группы радио-кнопок (`JRadioButton`).
  * **Формула 1**: $\sqrt{(\sin(y) + y^2 + e^{\cos(y)})^2 + (\ln(z^2) + \sin(\pi \cdot x^2))^3}$
  * **Формула 2**: $\sqrt{y} \cdot \frac{3 \cdot z^x}{\sqrt{1 + y^3}}$
* **Валидация данных**: Встроенная проверка деления на ноль, извлечения корня из отрицательного числа и взятия некорректных логарифмов с выводом диалогового окна ошибки (`JOptionPane`).
* **Регистры памяти**:
  * `M+` — Добавление текущего результата вычисления к значению в памяти.
  * `MC` — Очистка регистра памяти.
* **Адаптивный интерфейс**: Использование контейнеров `Box` с вертикальной и горизонтальной укладкой для сохранения пропорций при изменении размеров окна.

## 📂 Структура проекта

* `Formula.java` — Основной класс графического интерфейса (`JFrame`), содержащий математическую логику расчетов, разметку компонентов (`JTextField`, `JLabel`, `Box`) и обработчики событий кнопок.
* `Main.java` — Точка входа в программу (`main`), инициализирующая и отображающая окно калькулятора.

## 🛠️ Инструкция по запуску

### Компиляция проекта:
```bash
javac Main.java Formula.java
```

### Запуск приложения:
```bash
java Main
```

## 📋 Требования
* JDK 8 или выше
* Поддержка графической библиотеки `javax.swing` и `java.awt`
